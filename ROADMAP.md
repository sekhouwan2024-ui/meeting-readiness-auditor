# Roadmap

## 0.1 — Public baseline

- Publish the installable Codex Skill, deterministic extractors, schema validators, report renderer, synthetic demo, and end-to-end CI.
- Document local-data handling, known limits, and safe contribution practices.

## 0.2 — Reproducible evaluations

- Add a synthetic multilingual fixture set covering arithmetic errors, definition drift, time-window mismatch, misleading charts, and unsupported causal claims.
- Measure evidence citation completeness, false-positive rate, unsupported certainty, and cross-output consistency.
- Publish evaluation commands and machine-readable results.

## 0.3 — Broader document coverage

- Improve scanned-PDF and image-only chart review without weakening evidence boundaries.
- Add pluggable domain lenses and contributor-maintained regression cases.
- Test cost-efficient model configurations for individual maintainers and small teams.

Roadmap items are proposals, not promises. Priorities will follow reproducible bug reports, real adoption, and contributor feedback.
