# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please report vulnerabilities through GitHub's private vulnerability reporting or Security Advisories for this repository. Do not include confidential source documents or real customer data in a public issue.

The scripts are intended to process untrusted office files locally. Avoid running them with elevated privileges, review optional system converters before installation, and use isolated test material when investigating parser failures.
